1. MİMARİ GENEL BAKIŞ
🎯 TEK BACKEND, ÜÇ TÜKETİCİ
Bu projede tek bir backend (CodeIgniter 4) var, üç farklı tüketici bu backend'i kullanır:1. Web (Tarayıcı) → HTML sayfaları2. API (JSON) → Mobil uygulama için3. Mobil (Flutter/React Native) → API'yi tüketirHepsi aynı veritabanını kullanır, sadece giriş noktaları farklıdır.

1.2. Veri Akışı
Web Akışı (Tarayıcı)
1. Kullanıcı tarayıcıda /arama adresini açar
2. Route sistemi isteği Web\HomeController::search metoduna yönlendirir
3. Controller, InstitutionService->getFilteredList(...) metodunu çağırır
4. Service, InstitutionModel ile veritabanından verileri çeker
5. Controller, veriyi app/Views/home/search.php dosyasına gönderir
6. View, HTML sayfası oluşturur ve tarayıcıya döner

API/Mobil Akışı (JSON)
1. Mobil uygulama GET /api/v1/institutions isteği gönderir
2. Route sistemi isteği Api\V1\InstitutionController::index metoduna yönlendirir
3. Controller, InstitutionService->getFilteredList(...) metodunu çağırır
4. Service, InstitutionModel ile veritabanından verileri çeker
5. Controller, veriyi JSON formatında döner
6. Mobil uygulama bu JSON'ı alıp ekranda render eder

💡 KRİTİK NOKTA
Web ve API akışları AYNI SERVICE'İ kullanır!InstitutionService->getFilteredList() metodu hem Web hem API tarafından çağrılır.İş kuralı sadece bir kere yazılır, iki taraf da kullanır.


2. KİMLİK DOĞRULAMA (AUTH) VE YETKİLENDİRME
2.1. Web Authentication (Session Tabanlı)
Web tarafında klasik session tabanlı kimlik doğrulama kullanılır:
Giriş: Kullanıcı email/şifre ile giriş yapar → Session oluşur
Session: CodeIgniter session library kullanılır
Filter: AuthFilter: Giriş yapmış mı kontrol eder
Admin Filter: AdminFilter: Admin rolü var mı kontrol eder
Çıkış: Session destroy edilir

2.2. API Authentication (Token Tabanlı)
API/Mobil tarafında Bearer Token kullanılır:
Login: POST /api/v1/auth/login → Token üretir
Token Format: Authorization: Bearer eyJ0eXAiOiJKV1QiLCJhbGc...
Token Doğrulama: ApiAuthFilter: Her istekte token kontrolü yapar
Token Saklama: Mobil uygulama token'ı güvenli şekilde saklar
Logout: Token silinir veya iptal edilir

2.3. Filter Çalışma Mantığı
Filter'lar route'a bağlanır ve Controller'dan ÖNCE çalışır:
// Route tanımı$routes->group('panel', ['filter' => 'auth'], function($routes) {    $routes->get('/', 'Web\PanelController::dashboard');});// Akış:1. /panel isteği gelir2. AuthFilter devreye girer3. Session var mı kontrol eder4. Yoksa /giris sayfasına yönlendirir5. Varsa PanelController::dashboard çalışır

4. KRİTİK PRENSİP: İŞ KURALI SERVICE'DE
4.1. Neden Service Katmanı?
✅ Tek Kaynak: İş kuralı sadece Service'te yazılır, Controller'da değil
✅ Tekrar Kullanım: Web ve API aynı Service'i kullanır, kod tekrarı olmaz
✅ Tutarlılık: Mantık değişince sadece Service'te değişiklik yapılır
✅ Test Edilebilirlik: Service'ler unit test edilebilir
✅ Bakım Kolaylığı: İş kuralı tek yerde olduğu için bakımı kolay

4.2. Doğru vs Yanlış Yaklaşım
❌ YANLIŞ YAKLAŞIM (Controller'da iş kuralı):
// Web Controllerpublic function search() {    $institutions = $this->institutionModel        ->where('status', 1)        ->where('city_id', $this->request->getGet('city'))        ->orderBy('created_at', 'DESC')        ->paginate(20);        return view('home/search', ['data' => $institutions]);}// API Controller (AYNI KODU TEKRAR YAZMAK ZORUNDA!)public function index() {    $institutions = $this->institutionModel        ->where('status', 1)        ->where('city_id', $this->request->getGet('city'))        ->orderBy('created_at', 'DESC')        ->paginate(20);        return $this->response->setJSON($institutions);}SORUN: İş kuralı iki yerde yazılmış, değişiklik iki yerde yapılmalı!

✅ DOĞRU YAKLAŞIM (Service'te iş kuralı):
// Service (İş kuralı TEK YERDE)class InstitutionService {    public function getFilteredList($filters) {        return $this->model            ->where('status', 1)            ->where('city_id', $filters['city'] ?? null)            ->orderBy('created_at', 'DESC')            ->paginate(20);    }}// Web Controller (Sadece Service çağırır)public function search() {    $filters = ['city' => $this->request->getGet('city')];    $data = $this->institutionService->getFilteredList($filters);    return view('home/search', ['data' => $data]);}// API Controller (Aynı Service'i kullanır)public function index() {    $filters = ['city' => $this->request->getGet('city')];    $data = $this->institutionService->getFilteredList($filters);    return $this->response->setJSON($data);}ÇÖZÜM: İş kuralı sadece Service'te, değişiklik tek yerden yapılır!
