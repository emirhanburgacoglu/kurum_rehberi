CI4'ü kurmak için iki yöntem var. Composer varsa daha kolay, yoksa manuel kurarız.

1.3 Proje Klasör Yapısı
CI4 kurulumu sonrası şu klasör yapısı oluşur. Hangi klasörün ne işe yaradığını bil:
kurum-rehberi/
├── app/
│   ├── Controllers/      ← Sayfaların mantığı buraya yazılır
│   ├── Models/           ← Veritabanı sorguları buraya yazılır
│   ├── Views/            ← HTML şablonları buraya yazılır
│   ├── Config/           ← Veritabanı, route ayarları buraya
│   └── Helpers/          ← Yardımcı fonksiyonlar buraya
├── public/               ← CSS, JS, resimler buraya (dışarıdan erişilen)
│   ├── css/
│   ├── js/
│   └── uploads/          ← Kurum fotoğrafları buraya yüklenecek
├── writable/             ← CI4'ün log, cache dosyaları (dokunma)
└── .env                  ← Veritabanı şifresi, site ayarları (GİZLİ TUT!)

1.4 .env Dosyasının Ayarlanması
.env dosyası projenin en önemli ayar dosyasıdır. Veritabanı bağlantı bilgileri burada durur.
Proje kök dizinindeki env dosyasını kopyala, adını .env yap
VS Code ile .env dosyasını aç ve şu satırları düzenle:
# Geliştirme modunu aktif et (hata mesajları görmek için)
CI_ENVIRONMENT = development
 
# Veritabanı bağlantısı
database.default.hostname = localhost
database.default.database = kurum_rehberi
database.default.username = root
database.default.password =
database.default.DBDriver = MySQLi
 
# Site URL'i
app.baseURL = 'http://localhost/kurum-rehberi/public/'

Güvenlik Uyarısı:  .env dosyasını asla GitHub'a yükleme! .gitignore dosyasında .env satırının olduğundan emin ol.

Görev 2.3 — Slug Oluşturma
Her kurumun URL'de kullanılacak benzersiz bir slug'ı olmalı.
// Örnek: "ÖZEL CEYHAN EGEM ANAOKULU" → "ozel-ceyhan-egem-anaokulu"
// CI4'te bir Helper fonksiyonu yazacağız:
function create_slug($text) {
    $tr = ['ş','ğ','ü','ö','ı','ç','Ş','Ğ','Ü','Ö','İ','Ç'];
    $en = ['s','g','u','o','i','c','s','g','u','o','i','c'];
    $text = str_replace($tr, $en, $text);
    $text = strtolower($text);
    $text = preg_replace('/[^a-z0-9]+/', '-', $text);
    return trim($text, '-');
}

Görev 3.3 — İlk Model'i Yaz
<?php
// app/Models/InstitutionModel.php
namespace App\Models;
use CodeIgniter\Model;
 
class InstitutionModel extends Model {
    protected $table      = 'institutions';
    protected $primaryKey = 'id';
    protected $allowedFields = [
        'user_id', 'category_id', 'sub_category_id', 'city_id',
        'district_id', 'name', 'slug', 'kurum_turu', 'address',
        'phone', 'whatsapp', 'email', 'website', 'description',
        'logo', 'latitude', 'longitude', 'price_min', 'price_max',
        'status', 'is_featured', 'view_count'
    ];
    protected $useTimestamps = true;
    
    // Şehir + kategori bazlı arama
    public function search($city_id = null, $district_id = null, 
                           $category_id = null, $keyword = null) {
        $builder = $this->where('status', 1);
        if ($city_id)     $builder->where('city_id', $city_id);
        if ($district_id) $builder->where('district_id', $district_id);
        if ($category_id) $builder->where('category_id', $category_id);
        if ($keyword)     $builder->like('name', $keyword);
        return $builder->orderBy('is_featured', 'DESC')
                       ->orderBy('view_count', 'DESC')
                       ->paginate(20);
    }
}

<?php
// app/Filters/AuthFilter.php
namespace App\Filters;
use CodeIgniter\HTTP\RequestInterface;
use CodeIgniter\HTTP\ResponseInterface;
use CodeIgniter\Filters\FilterInterface;
 
class AuthFilter implements FilterInterface {
    public function before(RequestInterface $request, $arguments = null) {
        if (!session()->get('user_id')) {
            return redirect()->to('/giris')->with('error', 'Giriş yapmanız gerekiyor');
        }
    }
    public function after(RequestInterface $request, ResponseInterface $response, $arguments = null) {}
}

7.2 .htaccess Dosyası Ayarı
CI4'te URL'lerin düzgün çalışması için .htaccess dosyası şart. Bu dosya olmadan tüm sayfalar 404 verir.
public/.htaccess dosyası (CI4 varsayılan olarak gelir):
# public/.htaccess
RewriteEngine On
RewriteCond %{REQUEST_FILENAME} !-f
RewriteCond %{REQUEST_FILENAME} !-d
RewriteRule ^(.*)$ index.php/$1 [L]

XAMPP'ta mod_rewrite aktif etme:
XAMPP Control Panel -> Config -> Apache (httpd.conf) dosyasini ac
"#LoadModule rewrite_module" satirini bul, basinaki # isaretini kaldir
XAMPP'i yeniden baslatir
Artik /public olmadan URL calismali: localhost/kurum-rehberi/giris
/public klasorunu gizlemek icin ana dizine .htaccess:
# kurum-rehberi/.htaccess (ana dizin)
<IfModule mod_rewrite.c>
    RewriteEngine on
    RewriteRule ^$ public/ [L]
    RewriteRule (.*) public/$1 [L]
</IfModule>

Sonuc:  Bu ayardan sonra URL localhost/kurum-rehberi seklinde calisir, /public yazman gerekmez.

BÖLÜM 9 — Koordinat Ekleme (Geocoding)

MEB verisinde koordinat bilgisi yok. Adres bilgisinden otomatik olarak enlem/boylam koordinati uretmek icin Google Geocoding API kullanacagiz.
9.1 Google API Key Alma
console.cloud.google.com adresine git, Google hesabinla giris yap
"Yeni Proje" olustur: kurum-rehberi
Sol menu -> APIs & Services -> Library
"Geocoding API" ve "Maps JavaScript API" yi bul ve aktif et
APIs & Services -> Credentials -> Create Credentials -> API Key
API anahtarini kopyala, .env dosyasina ekle: GOOGLE_MAPS_KEY = AIza...
Ucretsiz Limit:  Google Geocoding API ayda 200 dolar kredisi ucretsiz veriyor. Bu yaklasik 40.000 istek demek. Baslangic icin fazlasiyla yeterli.

9.2 Toplu Koordinat Ekleme Scripti
<?php
// app/Controllers/Admin/Geocode.php
// Bu script'i sadece bir kez calistirirsin
namespace App\Controllers\Admin;
use App\Models\InstitutionModel;
 
class Geocode extends BaseController {
    public function run() {
        $model  = new InstitutionModel();
        $apiKey = env('GOOGLE_MAPS_KEY');
 
        // Koordinati olmayan kurumlari al (gunluk 500 islem yap)
        $kurumlar = $model->where('latitude', null)
                          ->where('status', 1)
                          ->limit(500)
                          ->findAll();
 
        $basarili = 0;
        foreach ($kurumlar as $kurum) {
            $adres   = urlencode($kurum->address . ', Turkiye');
            $url     = "https://maps.googleapis.com/maps/api/geocode/json"
                     . "?address={$adres}&key={$apiKey}&language=tr";
            $sonuc   = json_decode(file_get_contents($url), true);
 
            if ($sonuc['status'] === 'OK') {
                $lat = $sonuc['results'][0]['geometry']['location']['lat'];
                $lng = $sonuc['results'][0]['geometry']['location']['lng'];
                $model->update($kurum->id, [
                    'latitude'  => $lat,
                    'longitude' => $lng
                ]);
                $basarili++;
            }
            sleep(0.1); // API limitine takilmamak icin bekle
        }
        echo "{$basarili} kurum icin koordinat eklendi.";
    }
}

Dikkat:  Bu scripti /admin/geocode/run URL'ine giderek calistirirsin. Admin filtresi oldugu icin sadece admin gorebilir. Gunde bir kez calistir, kademeli olarak tum kurumlar koordinat kazanir.

BÖLÜM 12 — Resim Boyutlandirma ve Thumbnail

Kullanicilarin yukledigii fotograf 5MB olabilir. Bunu direkt gostermek hem yavaslatiir hem de gereksiz bant genisligi harcar. CI4'un Image sinifi ile yuklenen fotograflari optimize edecegiz.
12.1 Thumbnail Olusturma
<?php
// Fotograf yuklendiginde otomatik 3 boyut olustur:
// - original: Tam boyut (detay sayfasi icin)
// - medium:   800x600 (listeleme karti icin)
// - thumb:    400x300 (ana sayfa karti icin)
 
use CodeIgniter\Images\Services;
 
function processImage($sourcePath, $filename) {
    $uploadDir = FCPATH . 'uploads/institutions/';
 
    // Medium boyut (800px genislik)
    Services::image()
        ->withFile($sourcePath)
        ->resize(800, 600, true, 'width')
        ->save($uploadDir . 'medium/' . $filename);
 
    // Thumbnail (400px genislik)
    Services::image()
        ->withFile($sourcePath)
        ->resize(400, 300, true, 'width')
        ->save($uploadDir . 'thumb/' . $filename);
 
    // Orijinal dosyayi da tasi
    move_uploaded_file($sourcePath, $uploadDir . 'original/' . $filename);
}
 
// Klasor yapisi:
// public/uploads/institutions/original/foto.jpg  <- tam boyut
// public/uploads/institutions/medium/foto.jpg    <- 800x600
// public/uploads/institutions/thumb/foto.jpg     <- 400x300

BÖLÜM 15 — Cache Sistemi

Ayni sorguyu her sayfa yuklenisinde veritabanindan cekmek gereksiz. Sik degismeyen verileri (kategoriler, iller) cache'e alarak sayfa hizini arttirabiliriz.

<?php
// app/Controllers/Home.php - kategorileri cache'le
public function index() {
    $cache = \Config\Services::cache();
 
    // Once cache'de var mi bak
    $categories = $cache->get('all_categories');
 
    if (!$categories) {
        // Cache yoksa veritabanindan al
        $categoryModel = new CategoryModel();
        $categories = $categoryModel->findAll();
 
        // 30 dakika cache'e al (1800 saniye)
        $cache->save('all_categories', $categories, 1800);
    }
 
    return view('home/index', ['categories' => $categories]);
}
 
// Cache'i temizleme (kategori eklenince cagir)
$cache->delete('all_categories');
 
// Tum cache'i temizle
$cache->clean();

19.2 Sifre Degistirme Guvenlik Kontrolu
<?php
public function changePassword() {
    $userId  = session()->get('user_id');
    $user    = (new UserModel())->find($userId);
 
    // Once mevcut sifreyi dogrula
    if (!password_verify($this->request->getPost('current_password'), $user->password)) {
        return redirect()->back()->with('error', 'Mevcut sifreniz yanlis!');
    }
 
    // Yeni sifre uzunluk kontrolu
    $newPass = $this->request->getPost('new_password');
    if (strlen($newPass) < 8) {
        return redirect()->back()->with('error', 'Sifre en az 8 karakter olmali!');
    }
 
    // Yeni sifreyi hashle ve kaydet
    (new UserModel())->update($userId, [
        'password' => password_hash($newPass, PASSWORD_BCRYPT)
    ]);
 
    return redirect()->back()->with('success', 'Sifreniz guncellendi!');
}
